# Twitcher component reuse manifest

Pinned donor: `dominicbytes/twitcher` commit `5c80a758b1800ac74bdfa36cf2f0274013ba58dc`, itself derived from [Kani's original Twitcher](https://github.com/kanimaru/twitcher). The donor is MIT licensed; its Kani notice is preserved in `THIRD_PARTY_NOTICES.md`.

Redot Tuber is a standalone YouTube/Redot addon and has no runtime dependency on Twitcher. “Adapted” below means a component's narrow structural idea was deliberately ported and independently tested; it does not mean the complete Twitch subsystem was renamed.

| Donor path | Redot Tuber path or decision | Disposition | Modification / reason |
|---|---|---|---|
| `addons/twitcher/plugin.gd` | `addons/redot-tuber/plugin.gd` | Adapted | Retains the reversible `EditorPlugin` lifecycle shape; all Twitch menus, inspectors, importers, settings, assets, and service dependencies were removed. |
| `addons/twitcher/auth/twitch_auth_cancellation_token.gd` | `addons/redot-tuber/transport/cancellation_token.gd` | Adapted | Renamed, made idempotent, and given a secret-safe diagnostic reason and deterministic tests. |
| `addons/twitcher/tests/redot_compatibility.gd` | Redot Tuber compatibility runners | Adapted | The load-probe idea is expanded into milestone runners and full-project checks on Redot 26.2. |
| `addons/twitcher/lib/http/buffered_http_client.gd` | `addons/redot-tuber/transport/youtube_http_transport.gd` | Rejected / replaced | Donor behavior does not provide the claimed serialized queue and has retry/callback coupling. The replacement independently implements bounded concurrency, bounded request/response bodies, cancellation, retry, timeout, and redacted diagnostics. |
| `addons/twitcher/lib/http/http_server.gd` | OAuth loopback server | Rejected / replaced | Donor wildcard binding is unsuitable for authorization callbacks. Redot Tuber binds only `127.0.0.1` on an ephemeral port and validates state/PKCE. |
| `addons/twitcher/editor/api_generator/twitch_api_parser.gd` and generator model files | YouTube contract/model tooling | Rejected as code; data-model concept only | The donor parser is coupled to Twitch OpenAPI assumptions, contains format/type gaps, and generates Twitch-specific option types. Redot Tuber uses deterministic YouTube contracts and checked-in typed models. |
| Twitcher token cache and AES key provider | OS-vault helper plus non-secret descriptor | Rejected | A key stored beside an encrypted token file is not an OS credential boundary. Redot Tuber has no plaintext or key-beside-cache fallback. |
| Twitcher global service singleton | Per-node `YouTubeLiveClient` | Rejected | Each client owns one session slot/account and isolated transport/auth/quota state. |
| Twitch emote, badge, Cheermote, GIF, and ImageMagick components | `media/youtube_media_cache.gd` | Retrieval/cache boundary concept adapted; donor implementations rejected | Keeps only the useful idea of a centralized remote-media boundary. The implementation is independently bounded by HTTPS/type/item/aggregate/concurrency/TTL/LRU rules, supports clear-data, records no source URL on disk, and has no Twitch schema, ImageMagick, GIF importer, or donor asset dependency. |
| `addons/twitcher/lib/oOuch/oauth.gd` | `auth/youtube_oauth_session.gd`, `auth/youtube_auth_manager.gd` | Workflow adapted; protocol replaced | Retains the useful separation between authorization orchestration and token lifecycle. Twitch endpoints, implicit/device/client-credentials flows, cache loading, client-secret assumptions, and wildcard callback behavior were removed; Google authorization code + PKCE/state/IPv4-loopback is independently implemented and tested. |
| `addons/twitcher/lib/oOuch/oauth_token_handler.gd` and `addons/twitcher/auth/twitch_token_handler.gd` | `services/youtube_oauth_token_client.gd`, `auth/youtube_auth_manager.gd` | Lifecycle adapted; implementation replaced | Retains refresh/validation/revocation state ideas. Tokens are per client, access tokens remain memory-only, refresh tokens move through the RTCH/1 OS-vault pipe, and no singleton/cache Resource remains. |
| `addons/twitcher/lib/oOuch/oauth_token.gd` | `models/youtube_auth_token_set.gd` | Data shape adapted | Keeps an in-memory expiry/scopes value while removing file cache sections, encryption-key providers, implicit tokens, and editor Resources. |
| `addons/twitcher/auth/twitch_oauth_scopes.gd` | `auth/youtube_scope_registry.gd` | Concept adapted | Replaced Twitch scopes with an explicit YouTube capability-to-minimum-scope matrix and redundant-scope reduction. |
| `addons/twitcher/editor/setup/page_game_authorization.*` | `editor/youtube_setup_dialog.gd`, `ui/youtube_connection_panel.gd` | Workflow adapted | Retains discoverable setup/status UX, but runtime channel-owner consent is first class and no project credential/token Resource is created. |

When another donor file is copied or substantially adapted, this table must be updated in the same change.
